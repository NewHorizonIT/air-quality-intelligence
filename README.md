# Air Quality Intelligence Platform

An end-to-end data analytics project for analyzing air quality,
pollution patterns, temporal trends, geographic patterns,
and the relationship between air pollution and weather conditions.

## Project Status

🚧 In development

## Objectives

- Analyze air quality trends over time
- Identify pollution hotspots
- Analyze relationships between air quality and weather
- Build an interactive analytics dashboard
- Generate actionable insights from environmental data

## Tech Stack

- Python
- PostgreSQL
- SQL
- Pandas
- SciPy
- Statsmodels
- Scikit-learn
- Power BI
- Docker
